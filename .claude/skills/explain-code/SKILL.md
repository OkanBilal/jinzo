---
name: explain-code
description: Explains code with visual diagrams and analogies. Use when explaining how code works, teaching about a codebase, or when the user asks "how does this work?"
---

When explaining code, always include:

1. **Start with an analogy**: Compare the code to something from everyday life that makes the concept intuitive

2. **Draw a diagram**: Use ASCII art to show the flow, structure, or relationships
   ```
   Example:
   ┌─────────┐     ┌─────────┐     ┌─────────┐
   │  Input  │ ──▶ │ Process │ ──▶ │ Output  │
   └─────────┘     └─────────┘     └─────────┘
   ```

3. **Walk through the code**: Explain step-by-step what happens when the code runs

4. **Highlight key patterns**: Point out design patterns, idioms, or conventions used

5. **Mention gotchas**: What's a common mistake or misconception about this code?

Keep explanations conversational and accessible. For complex concepts, use multiple analogies.
