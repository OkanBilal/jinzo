# Replace the seed IPC module with the versioned seed runner

Seeding initial data was historically modelled as a regular IPC module: `src/main/modules/seed/` exposed `seed:accounts`, `seed:connections`, `seed:all`, etc., backed by `seed.service.ts` shims that delegated to `src/main/db/queries/seed-*.ts`. The renderer was expected to trigger seeding via `window.api.seed.*` during onboarding or "reset to defaults" flows.

That contract no longer holds. `src/main/db/seeds/` introduces a versioned, idempotent runner — `runSeeds(db)` reads `appSettings.seedVersion`, executes each unapplied `v{N}.ts`, and updates the version. `db/client.ts` invokes it automatically when the database is initialized, so every app launch (cold start or upgrade) converges to the latest baseline without renderer involvement. `db/seeds/v1.ts` carries the same data the old `db/queries/seed-*.ts` files used to insert; the comment at the top of `v1.ts` records that lineage. After this change there are zero callers of `api.seed.*` in `src/renderer`, the smoke test imports only `db/seeds`, and the only consumer of `db/queries/seed-*.ts` is the now-unused `seed.service`.

We removed the entire `src/main/modules/seed/` folder, the `src/main/db/queries/` folder (which only ever held seed code — no other domain used it), the `seed:` block in `src/preload/index.ts`, the `CHANNELS.seed` namespace, and the `registerSeedIpc` / `unregisterSeedIpc` calls in `src/main/index.ts`. The `src/main/db/data/` fixtures stay where they are; `db/seeds/v1.ts` still imports them. Seeding is now a database-layer concern owned by `db/seeds/`, not a domain module — there is intentionally no `src/main/modules/seed/` and there should not be one again.

The decision is hard to reverse (touches the IPC seam, preload, channel registry, and main entry point) and surprising without this context — a future reader sees no seed module and may wonder if it was forgotten. It wasn't: the seam moved from "IPC channel the renderer triggers" to "startup hook in `db/client`," and the IPC surface was vestigial dead code. Future architecture reviews should not propose re-introducing a seed module.
